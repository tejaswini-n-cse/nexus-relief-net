# Resilient Response Hub

You are an expert Senior Software Architect, UX Designer, and Full Stack Engineer.

Build a modern, production-quality web application called **ResQNet – AI Powered Smart Disaster Response & Relief Management Platform**.

The application should have an elegant, responsive UI with modern glassmorphism design, smooth animations, dark/light mode, beautiful dashboards, and professional color palette.

The platform should solve real-world disaster management problems during floods, earthquakes, cyclones, landslides, fires, and other emergencies.
